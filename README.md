## Example FDE Problem

### Design a Customer Support AI Agent

You are building an AI support system using:
- Customer records stored in Snowflake
- Internal policy documents
- Previous support transcripts
- Case notes

Design a system that can:
1. Retrieve relevant customer information.
2. Retrieve applicable company policies.
3. Generate grounded responses.
4. Escalate uncertain cases.
5. Log decisions for auditing.
6. Measure response quality and business impact.

Consider retrieval architecture, context construction, tool calling, security, evaluation, observability, latency, cost, and failure handling.

## Preparation Philosophy

Strong FDE candidates should be able to move between:

**Customer Problem → Requirements → Architecture → Implementation → Production → Evaluation**

The goal is not simply to answer interview questions. The goal is to demonstrate that you can build and deploy useful technical capabilities in ambiguous real-world environments.
